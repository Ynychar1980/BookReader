# Руководство для контрибьюторов

## Как внести вклад
1. Форкните репозиторий
2. Создайте ветку для своей фичи: `git checkout -b feature/your-feature`
3. Сделайте коммиты: `git commit -m "Add awesome feature"`
4. Запушьте в свой форк: `git push origin feature/your-feature`
5. Откройте Pull Request

## Требования к коду
- Все изменения должны покрываться тестами
- Соблюдайте стиль кодирования проекта
- Документируйте публичные методы
